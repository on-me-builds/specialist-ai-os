# 歯科医院向けAI/自動化市場 — 競合戦略分析レポート

> 分析日: 2026-03-23
> 対象: 日本の歯科医院向けB2B SaaS / AI Automation市場
> 目的: どこに crowded な領域があり、どこに wedge がありそうかを分析する

---

## Executive Verdict

**結論から言う。**

4文章生成は主商品ではない、という判断は正しい。「作って終わり」のアセットに月額課金する理由がない。

**今いちばん攻めるべきは「キャンセル/リコール自動化 × LINE」ではない。** ここは既にジニー・Apotool・DentNet等の予約システム勢が守備範囲に入れており、単体で入るには遅い。

**最も勝ちやすいのは「中断患者の呼び戻し + リコール最適化」を、既存予約システムが"やれると言っているが実際は手薄"な領域で、AI×LINEで圧倒的にラクにする "運用OS" として差し込むこと。** 予約システムを置き換えるのではなく、予約システムの上に乗る「リテンション層」を取る。

レセプトAIは規制・技術障壁が高すぎる。採用定着は人材紹介の成功報酬モデルに勝てない。MEOは差別化困難。

4文章生成は、初回ヒアリング時の「医院理解インテーク + 営業デモ」として残し、リード獲得装置に位置づけるのが最善。

## Market Structure Overview

### 市場の基本数字

| 項目 | 数値 |
|------|------|
| 日本の歯科医院数 | **約67,000**（コンビニ55,700超） |
| 歯科衛生士の有効求人倍率 | **約20倍** |
| 歯科衛生士の転職率 | **約70%** |
| 60歳以上の歯科医師割合 | **33.5%** |
| 平均キャンセル率（業界推計） | **10〜15%** |
| リコール実施率 | 医院によりバラつき大。自動化は少数派 |

### 医院が金を払う4つの痛み

1. **患者が来ない/戻らない**（集患・リコール・中断）← 売上直結
2. **人が採れない/辞める**（採用・定着）← 運営存続に関わる
3. **事務が回らない**（レセプト・受付・電話）← 時間の痛み
4. **競合に負ける**（MEO・口コミ・HP）← じわじわ効く

**カテゴリ判定: workable — ただしSaaSとして入るのは非常に難しい**

採用は「人が採れたか採れないか」がすべて。成功報酬型の求人サイトが強く、月額SaaSは「採れないのに毎月払う」不満が出やすい。デンタルHR総研（採用代行RPO）は成功率99%を謳い契約継続率98.6%。「採用OS」で月額課金するには「定着まで面倒を見る」か「採用ブランディング + 求人文を常時最適化」する仕組みが要る。

Nestaが歯科特化の動画マニュアルSaaSとして存在するが、定着支援・評価制度・1on1のOS化までは未到達。差別化余地はある。

## Threat Assessment

### 最大の脅威: 既存予約システム勢の機能拡張

Apotool・ジニー・DentNetは「予約」を入口に、LINE連携・リコール・中断患者管理・電話AI・分析と機能を広げている。**彼らが「運用OS」の方向に拡張してきたら、我々の入る余地が狭まる。**

ただし、彼らの弱点は明確:
- **予約管理UI最適化に開発リソースが集中**し、リテンション運用のUXは「機能はあるが使いこなせない」状態
- **AI活用は表面的**（リスト自動作成まで。メッセージ最適化・A/Bテスト・反応率改善は未実装）
- **スタッフが運用できない**問題を解いていない（ツールを入れても動かない医院が多い）

### 第二の脅威: メドレー（ジョブメドレー + Dentis）

メドレーは「採用（ジョブメドレー）」と「カルテ+レセプト（Dentis）」で歯科の基幹業務を押さえつつある。今後予約・LINE連携まで拡張したら、単独で歯科業務の大半をカバーする可能性がある。

ただし: メドレーは「汎用医療プラットフォーム」であり、歯科特化の深い運用支援には手が回っていない。ここに入る余地はある。

### 第三の脅威: Lステップ等の汎用LINEマーケツール

歯科特化ではないが、LINE上でのリマインド・セグメント配信・自動応答は既に実現できる。歯科医院が「Lステップ + 自力設定」で解決してしまうリスク。

ただし: 歯科特有のリコール周期・キャンセルパターン・患者セグメントは汎用ツールでは設定が面倒。**ここに特化する余地はある。**

## Best 3 Entry Wedges

### Wedge 1: 「中断患者リテンションOS」（最推奨）

**何を売るのか:**
中断患者（治療途中で来なくなった人）の自動検知 → LINE/SMSメッセージの自動配信 → 反応トラッキング → 再予約誘導 → 来院後の継続定着メッセージ、までを一気通貫で回すOS。

**誰に売るのか:**
ユニット3〜8台の中規模歯科医院。予約システム（Apotool/ジニー/DentNet）は入れているが、中断患者対応は「リストは見えるけど何もしていない」状態の院長。

**なぜ今これが刺さるのか:**
- 歯科医院の売上は「リピート率」で決まる。新患獲得（MEO/広告）はコスト高
- 中断患者1人の再来院 = 数万〜十数万円の治療売上
- ジニーやApotoolは「リストを出す」が、「何を送るか」「いつ送るか」「反応がなかったらどうするか」のシナリオは医院任せ
- AIで最適なメッセージ・タイミングを自動化できれば、スタッフの手を使わずに月10〜30万の売上回復が見込める

**既存競合とどこでズラすか:**
- 予約システムの「上に乗る」（置き換えない）
- 予約システムが出す中断患者リストを入力として受け取り、LINEメッセージシナリオを回す
- 「予約管理は今のまま。リテンション運用だけ任せて」というポジション

**月額課金にできる理由:**
- 「中断患者○人に配信 → ○人が再来院 → 推定回収額○万円」が毎月レポートで見える
- 止めたら中断患者が放置に戻る = 機会損失が可視化される
- 月2〜5万円で月10〜30万回収できるなら、ROIが明確

**MVPはどこまででいいか:**
- Google Sheets or CSV で中断患者リストを手動インポート
- LINE Official Account のメッセージ配信を n8n で自動化
- テンプレメッセージ3パターン（1週間後/2週間後/1ヶ月後）
- 反応率のトラッキング（既読/返信/予約確定）

**やってはいけない広がり方:**
- 予約管理機能を自前で持つ（Apotool/ジニーと正面衝突）
- 新患集客に手を出す（MEO業者と被る）
- レセコン連携に深入りする（技術負債が膨大）

---

### Wedge 2: 「歯科スタッフ定着OS」（次善）

**何を売るのか:**
新人スタッフのオンボーディングSOP自動生成 + 評価フィードバックの仕組み化 + 離職リスク検知。

**誰に売るのか:**
スタッフ5〜15名の医院。「衛生士が3ヶ月で辞める」「教育が属人化している」院長。

**なぜ今これが刺さるのか:**
- 衛生士の有効求人倍率20倍 = 採れたら「辞めさせない」が最優先
- 採用コストは1人40〜100万円（紹介料 + 求人広告）。定着すれば投資回収
- 教育SOPは院長の頭の中にしかない。言語化されていない
- AIで「業務マニュアル自動生成」「月次フィードバックテンプレ」「1on1ガイド」を提供できる

**既存競合とどこでズラすか:**
- 求人媒体（ジョブメドレー/グッピー）は「採るまで」。「採った後」は空白
- デンタルHR総研は「採用代行」。定着・教育は別料金 or 未対応
- Nestaは「動画マニュアル作成ツール」。評価制度・1on1・離職予防までは未実装
- 歯科コンサルは高額（月10〜30万）。SaaS月額で安価に提供する

**月額課金にできる理由:**
- 「辞めたら採用コスト100万」vs「月2万で定着支援」のROI
- 毎月のスタッフ状態レポート・フィードバックテンプレ更新

**MVPはどこまででいいか:**
- SOP生成（Product Factoryの延長で作れる）
- 月次1on1テンプレ + フィードバックシート
- 入社30/60/90日チェックリスト

**やってはいけない広がり方:**
- 求人媒体を作る（ジョブメドレーに勝てない）
- 給与計算・シフト管理に入る（勤怠SaaSと被る）

---

### Wedge 3: 「AI口コミ返信 + リコールメッセージ最適化」（補助モジュール）

**何を売るのか:**
Google口コミへのAI自動返信 + LINEリコールメッセージのA/B最適化をセットで月額提供。

**誰に売るのか:**
「口コミ放置」「リコールはがき/電話だけ」の医院。

**なぜ今これが刺さるのか:**
- 口コミ返信は「やった方がいいが面倒」の典型
- AI返信は品質が実用レベルに到達
- リコールメッセージの「文面」を最適化するサービスは存在しない
- この2つをセットで月1〜2万なら「やらない理由がない」価格帯

**MVPはどこまででいいか:**
- Google Business Profile APIで口コミ取得 → AI返信案生成 → 院長承認 → 投稿
- LINEリコールメッセージのテンプレ3パターン提供 + 反応率レポート

**やってはいけない広がり方:**
- MEO対策全般を引き受ける（差別化できない）
- HPリニューアルに手を出す（制作会社の領域）

## Positioning of the 4-Document Product Factory

4文章生成は**主商品にしない。以下の3つの役割に固定する。**

### 役割1: リード獲得用の無料デモ（Lead Magnet）
「医院情報を入力するだけで、FAQ・求人文・口コミ返信・提案書が即座に出ます」→ 初回接触の敷居を下げる。ChatGPT直利用との差別化は「歯科特化のプロンプト品質」と「一括生成の利便性」。

### 役割2: 顧客理解インテーク装置
Google Formsのヒアリング → 4文章生成の過程で、医院のservices/features/tone/課題を構造化データとして取得できる。これは主商品（リテンションOS等）の初期設定データとして再利用する。

### 役割3: 主商品のオンボーディングサンプル
「この品質の文章をAIが作れるなら、リコールメッセージや口コミ返信もお任せください」→ 主商品への橋渡し。

**月額課金はしない。あくまで入口と理解装置。**

## Recommended Direction

### 今いちばん攻めるべきテーマ
**中断患者リテンションOS**。理由：
- ROIが明確（中断患者1人の再来院 = 数万〜十数万円）
- 既存予約システムと正面衝突しない（補完関係）
- AI×LINEの組み合わせで差別化可能
- Product Factoryのパイプライン（n8n + Python）をそのまま転用可能

### まだやるべきではないテーマ
- **レセプトAIチェック**（技術負債・規制リスクが大きすぎる。Dentis/メドレーの領域）
- **MEO主戦場**（業者多数・差別化困難・解約されやすい）

### 4文章生成の位置づけ
**Lead Magnet + インテーク装置として維持。** 主商品へのオンボーディングに組み込む。月額課金商品にはしない。

## Kill Tests

主商品候補を検証する際の「これが通らなければ撤退」基準。

### 中断患者リテンションOS
1. **院長5人にヒアリングして、3人以上が「中断患者対応に月2〜5万円は払う」と言うか？**
2. **実際に中断患者リストを出せる医院が3院以上あるか？**（データ取得の壁）
3. **LINE配信後、2週間以内に中断患者の5%以上が反応するか？**

### 歯科スタッフ定着OS
1. **院長5人にヒアリングして、「SOP/教育にSaaSで月額は払う」と言うか？**
2. **「教育マニュアルが欲しい」と「月額課金してでも欲しい」の間にギャップはどれくらいか？**
