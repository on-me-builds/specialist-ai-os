# /review-pack コマンド

生成済みのテンプレートパックをレビューし、品質レポートを出力する。

## 手順

1. パック検証を実行する
   ```bash
   python factory/scripts/validate_pack.py
   ```

2. 各ファイルの内容をざっと読み、以下の観点でレビューする

### レビュー観点

#### 構造チェック
- H1見出しに医院名が入っているか
- セクション構成が適切か
- Markdown記法が正しいか

#### コンテンツチェック
- 医院名・特徴がプロフィールと一致しているか
- トーンがプロフィール指定と一致しているか
- 未解決変数（`{xxx}`）が残っていないか

#### コンプライアンスチェック
- 「日本一」「最先端」「絶対」などの禁止表現がないか
- 医療広告ガイドライン的に問題のある記述がないか

3. レビュー結果をまとめて報告する
   - ✅ 問題なし / ⚠️ 要確認 / ❌ 修正必要 の3段階で評価

## 引数
- `$ARGUMENTS` にパックディレクトリのパスが渡された場合はそのパスを検証する
- 引数なしの場合は `output/generated/sample_clinic/` をレビューする
