# 院長ヒアリングシート（30分）

> 目的: 中断患者の見える化・呼び戻し運用づくりの導入可否を確認する
> 所要時間: 30分
> 使い方: 上から順に聞く。感覚ベースの回答でOK。数字は後半で聞けたら聞く。
> ★ = 必須　無印 = スキップ可

## B. 取りこぼしの現状を聞く（10分）★最重要

> このセクションでは数字を聞かない。まず現場の印象と困り感を拾う。

| # | 質問 | 回答欄 | 備考 |
|---|------|--------|------|
| ★B1 | 最近、予約の変更や無断キャンセルは多い印象ですか？ | | 「多い/まあまあ/少ない」で十分 |
| ★B2 | 治療途中で来なくなる患者さん（中断患者）はいますか？ | | 「いる/たまに/あまり気にしていない」 |
| ★B3 | その方たちに対して、今何かしていますか？ | | 例: 電話 / はがき / 何もしていない |
| ★B4 | それをやっているのは誰ですか？ルールはありますか？ | | 院長 / 受付 / 特に決まっていない |
| B5 | 戻ってくることはありますか？ | | 「たまにある/ほぼない/わからない」 |
| B6 | 中断患者を放置していることに対して、もったいないと感じますか？ | | 本音を聞く。ここが pain の核心 |

## C. データの状況を確認する（5分）

> 無理に数字を出させない。「出せるか」「見えるか」だけ確認する。

| # | 質問 | 回答欄 | 備考 |
|---|------|--------|------|
| ★C1 | だいたい何人くらいいそうですか？（感覚で大丈夫です） | | 「10人くらい」「もっといそう」程度でOK |
| ★C2 | 予約履歴や名簿から、最近来ていない患者さんを拾えそうですか？ | | 画面で見えるだけでもOK |
| C3 | CSVやExcelに出す機能はありそうですか？ | | 操作に不安があればこちらでサポート |
| C4 | （出せない場合）受付の方が手元で名前を挙げられそうですか？ | | 10人でも手書きリストで始められる |
