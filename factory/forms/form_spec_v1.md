# Clinic Profile Form Spec v1

## 目的

院長ヒアリングの内容を、Google Forms / Notionフォーム / n8n webhook で受け取れる形に標準化する。
このフォームの回答から `clinic_profile.yaml` を自動生成し、Product Factory に渡す。

## 想定入力者

| 入力者 | 状況 |
|--------|------|
| **院長本人** | ヒアリング前に事前記入してもらう |
| **営業担当（代行入力）** | ヒアリング時のメモから入力する |

→ どちらでも **3〜5分で完了** できる分量に抑える。

## 設計方針

- 質問は自然な日本語で、専門用語を避ける
- 選択肢があるものは checkbox / select を使い、自由記述を減らす
- 必須項目は3つだけ（医院名・診療内容・特徴）
- 残りは任意。空欄ならデフォルト値を使う

## 入力時の注意点

1. **必須は3項目だけ**: 医院名・診療内容・特徴。残りは空欄OK
2. **選択肢 + 自由記入**: checkboxには必ず「その他（自由記入）」欄を付ける
3. **Q10（採用詳細）が最も記入しにくい**: 空欄でも動くように設計する
4. **フォーム冒頭に所要時間を明記**: 「3〜5分で完了します」
5. **個人情報は聞かない**: 院長名・連絡先等はフォームに含めない（別途管理）

## フォーム全体の構成

| セクション | 質問数 | 所要時間目安 |
|-----------|:------:|:----------:|
| 基本情報 | 2問 | 30秒 |
| 診療内容 | 1問 | 30秒 |
| 医院の特徴 | 1問 | 30秒 |
| 予約・お支払い | 4問 | 1分 |
| 採用情報 | 2問 | 1分 |
| トーン・その他 | 2問 | 30秒 |
| **合計** | **12問** | **約4分** |
