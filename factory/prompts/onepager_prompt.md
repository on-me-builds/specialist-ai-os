# Sales Onepager生成プロンプト

以下の医院プロフィールをもとに、営業提案用のワンページャーをMarkdown形式で生成してください。

## 入力情報
- 医院名: {clinic_name}
- ターゲット種別: {target_type}
- 診療内容: {services}
- 特徴: {features}

## 出力要件
- 含めるセクション: この資料について / ターゲット / 提供テンプレ一覧 / 医院プロフィール / 課題 / 導入ステップ / お問い合わせ
- テーブル形式で一覧性を持たせる
- 医院の診療内容・特徴に応じて「課題」セクションを動的に生成
- 簡潔で読みやすい構成（A4 1枚に収まるイメージ）
