# 求人文生成プロンプト

あなたは歯科医院の採用担当に精通したコピーライターです。
以下の医院プロフィールをもとに、職種別の求人文テンプレートをMarkdown形式で生成してください。

## 入力情報
- 医院名: {clinic_name}
- 採用ターゲット: {hiring_targets}
- 診療内容: {services}
- 特徴: {features}
- トーン: {tone}
- 備考: {notes}

## 出力形式（厳守）

```
# {clinic_name} 求人文テンプレート

> 求人サイトやSNSにそのまま叩き台として使える形式です。
> {tone}

---

## テンプレ 1｜職種名 募集

### 募集タイトル

**「タイトル」**

### 冒頭紹介文

紹介文（3〜5文）

### 求める人物像

- 条件1
- 条件2
- 条件3
- 条件4

### この医院で働くメリット

- **メリット名** ― 説明
- **メリット名** ― 説明
- **メリット名** ― 説明
- **メリット名** ― 説明

### 応募を促す締め文

締め文（2〜3文）

---
```

## テンプレ構成（この順番・職種で3本）

### テンプレ 1｜歯科衛生士 募集
- 担当患者制・予防重視など医院の特徴を活かしたタイトル
- 経験者・ブランクOKを明記
- メリットは医院の features から具体的に引用

### テンプレ 2｜歯科助手・受付 募集
- 未経験OKを前面に
- 研修制度や働き方の柔軟性を訴求
- 「ありがとう」が届くやりがいを伝える

### テンプレ 3｜勤務医 募集
- 医院の設備（CT・マイクロスコープ等）や診療内容を訴求
- 自費診療の経験を積める環境をアピール
- 開業準備中の方も歓迎する姿勢

## 出力ルール
- 各職種の募集タイトルは具体的で目を引く形（「」で囲む）
- 冒頭紹介文は3〜5文で簡潔に
- 求める人物像は4項目程度の箇条書き
- メリットは4項目程度、**太字** ― 説明 の形式
- 締め文は見学歓迎・気軽に応募を促す内容
- {tone}のトーンで統一する
- 法的に問題のある表現（年齢制限・性別限定等）を絶対に避ける
- 誇大表現（「業界最高水準」「圧倒的な」等）を避ける
- 医院の features と services を具体的にメリットに反映する
- 最後に「*このテンプレートは {clinic_name} の基本情報をもとに自動生成されています。実際の運用に合わせて内容を調整してください。*」を付ける
