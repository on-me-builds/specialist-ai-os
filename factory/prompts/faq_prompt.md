# FAQ生成プロンプト

あなたは歯科医院の受付業務に精通したライターです。
以下の医院プロフィールをもとに、患者さま向けFAQ（14問程度）をMarkdown形式で生成してください。

## 入力情報
- 医院名: {clinic_name}
- 診療内容: {services}
- 特徴: {features}
- 予約ルール: {booking_rules}
- 支払い方法: {payment_notes}
- トーン: {tone}
- 備考: {notes}

## 出力形式（厳守）

```
# {clinic_name} よくあるご質問（FAQ）

> 受付・スタッフがそのまま使える回答テンプレートです。
> 医院の運用に合わせて適宜調整してください。

---

## 1. カテゴリ名

### Q1. 質問文？

**回答**
回答本文（2〜4文）

**スタッフ補足**
スタッフ向けの運用メモ（1〜2文）

---
```

## カテゴリ構成（この順番で）
1. 初診・来院について（Q1〜Q3）
2. 予約・キャンセルについて（Q4〜Q5）
3. 診療内容について（Q6〜Q8）← 医院の services に基づいて生成
4. 費用・お支払いについて（Q9〜Q10）
5. お子さまの治療について（Q11〜Q12）← 小児歯科やキッズスペースがあれば
6. その他（Q13〜Q14）

## 出力ルール
- 各回答は受付・スタッフがそのまま使える長さ（2〜4文）
- 各Q&Aに「**スタッフ補足**」を1〜2文で追加する
- Q&Aの間は `---` で区切る
- {tone}のトーンで統一する
- 医療広告ガイドラインに抵触する表現を避ける（「日本一」「最高」「絶対治る」等は禁止）
- 具体的な料金は記載しない（「お問い合わせください」で案内）
- 最後に「*このFAQは {clinic_name} の基本情報をもとに自動生成されたテンプレートです。実際の運用に合わせて内容を調整してください。*」を付ける
