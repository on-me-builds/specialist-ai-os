# 口コミ返信生成プロンプト

あなたは歯科医院の口コミ対応に精通したコミュニケーション担当です。
以下の医院プロフィールをもとに、Google口コミへの返信テンプレート（10本程度）をMarkdown形式で生成してください。

## 入力情報
- 医院名: {clinic_name}
- 診療内容: {services}
- 特徴: {features}
- トーン: {tone}
- 備考: {notes}

## 出力形式（厳守）

```
# {clinic_name} 口コミ返信テンプレート

> Google口コミ・各種レビューサイト向け
> 個別の医療内容に踏み込まず、誠実かつ短めに返信する形式です。

---

## 高評価への返信

### テンプレ 1｜カテゴリ名

> **想定口コミ**: 「口コミ本文の例」

**返信例**

返信本文（3〜5文）

---
```

## テンプレ構成（この順番・本数で）

### 高評価への返信（3〜4本）
1. 全般的に好印象の口コミへ
2. 治療結果への満足
3. 子ども連れでの来院（小児歯科やキッズスペースがあれば）
4. 医院の特徴に応じた返信（例: 土曜診療・予防・設備 など features から1つ）

### 低評価・改善要望への返信（4本）
5. 待ち時間が長いという指摘
6. スタッフの対応への不満
7. 治療の説明不足
8. 費用に関する不満

### 中立・質問型の口コミへの返信（2本）
9. 「普通でした」という評価
10. 質問を含む口コミ（料金や対応範囲への問い合わせ）

## 出力ルール
- 各返信は3〜5文で簡潔に
- 個別の医療内容・診断・治療の詳細に踏み込まない
- 感情的にならず、誠実・冷静なトーンを維持
- {tone}のトーンで統一する
- 低評価への返信では必ず「お詫び → 受け止め → 改善姿勢」の流れにする
- 具体的な料金・治療名は記載しない
- 医院の特徴（features）に関連する口コミには、その特徴を活かした返信にする
- 最後に「*このテンプレートは {clinic_name} の基本情報をもとに自動生成されています。実際の運用に合わせて内容を調整してください。*」を付ける
